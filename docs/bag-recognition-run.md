# Просмотр depth-панорам и прогон распознавания — 23.09.2026

## Что проверено

В этом отчёте обработаны шесть коротких rosbag: пять отрицательных и один
положительный `doubleT_obstacle`; все сопоставлены с
[описанием владельца](../evaluation/scene_context.yaml). Длинный `new_data`
по просьбе пользователя исключён из текущей разметки и прогона распознавания.
Для этих шести записей просмотрены выборки из имеющихся MP4-панорам глубины
`../../videosasda/*.mp4` (каждую 1 с; для положительной записи дополнительно
каждые 0,5–1 с вокруг выхода человека). Это выборочный просмотр, а не
непрерывная проверка каждого кадра.

Положительный участок в `doubleT_obstacle` размечен отдельно в
[annotations/doubleT_obstacle.yaml](../evaluation/annotations/doubleT_obstacle.yaml)
по `bag_stamp_ns`. До +11,985 с на просмотренных панорамах человека нет;
появление и переход к пути между +11,985 и +17,000 с помечены `uncertain`;
+17,000…+20,392 с — консервативный положительный интервал. Объект различим
на прямых выборках PointCloud2. Его расстояние не размечено: оси полного скана
и метрический габарит пути не подтверждены. Для остальных bag отсутствие
препятствия на пути сообщено владельцем и поддерживается выборочным просмотром,
но сплошная независимая покадровая разметка пока не заявляется.

## Артефакты и воспроизведение

JSONL и `summary.json` для каждого bag находятся в игнорируемом Git каталоге
`results/annotation-review/<bag>/`. Исходные bag не копировались. Для
forward-sector использован вызов вида:

```bash
ros2 run metro_perception_ros evaluate_bag \
  /data/archive/doubleT_platform /lidar_points \
  /results/doubleT_platform/frames.jsonl \
  /data/metro-lidar-processing/metro_perception_ros/config/forward_sector_assumed.yaml
ros2 run metro_perception_tools metrics \
  /results/doubleT_platform/frames.jsonl \
  --output /results/doubleT_platform/summary.json
```

Контейнеру переданы `/home/vladislav/vuz/hahaton:/data:ro` и
`/home/vladislav/vuz/hahaton/metro-lidar-processing/results/annotation-review:/results:rw`.
