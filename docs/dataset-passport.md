# Паспорт шести коротких LiDAR bag (D1, промежуточный)

Проверено 23.09.2026 в локальной рабочей среде. Пять отрицательных записей
лежат в `/home/vladislav/vuz/hahaton/archive/<bag_id>/`, положительная — в
`rosbags/doubleT_obstacle/` репозитория. В прежних прогонах родительский
каталог монтировался в `/data:ro`, а пять отрицательных bag читались из
`/data/archive/<bag_id>/`; положительный bag находится отдельно в
`/data/metro-lidar-processing/rosbags/doubleT_obstacle/`. `dataset.yaml`
задаёт ID и темы, но его относительные пути пока не образуют единый
воспроизводимый корень для всех шести bag. Данные
предоставлены локально; право публикации и постоянный адрес получения не
подтверждены. `new_data` в этот паспорт и текущую разметку не входит.

Для всех шести `metadata.yaml` объявляет SQLite3 и `sensor_msgs/msg/PointCloud2`.

[`evaluation/short-bags.sha256`](../evaluation/short-bags.sha256). Для
проверки выполнять `sha256sum -c` из корня репозитория после предоставления
пяти каталогов `/home/vladislav/vuz/hahaton/archive`; пути в файле абсолютны
для этой машины, поэтому на другом стенде их нужно сопоставить с локальным
корнем данных.

Пять секторных bag обрабатываются профилем
`metro_perception_ros/config/forward_sector_assumed.yaml`: предполагается
`forward = -sensor Y`, `left = +sensor X`, `up = +sensor Z`, перенос нулевой,
`calibration_verified: false`. Для `doubleT_obstacle` штатный
`full_scan_unresolved.yaml` не выбирает направление движения и остаётся
`UNKNOWN`. Исследовательский поворот `-Y → X` в G2 не является измеренной
калибровкой. Полуширина коридора 2 м и высота 3,5 м — параметры алгоритма,
а не согласованный габарит подвижного состава.

**Осталось для закрытия D1:** согласовать единый корень/manifest входных
путей, подтвердить mounting/extrinsics и габарит с
владельцем данных, проверить source `frame_id` и состав/размер облаков на всех
кадрах, оформить воспроизводимый источник передачи приватных данных и права
на их распространение. Паспорт фиксирует доступные факты, но не объявляет
калибровку проверенной.
