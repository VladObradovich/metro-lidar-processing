# Алгоритм — заготовка описания

Статус: геометрический детектор НЕ РЕАЛИЗОВАН. Сейчас доступен только безопасный
декодер XYZ; измеренные timings каркаса не характеризуют будущий алгоритм.

Заполнять по мере реализации A02–A07:

1. Проверка входа и ближняя маска в sensor frame до transform.
2. TF → целевая система; sensor origin хранится в той же системе.
3. Широкая geometry ROI, опорная поверхность и качество поддержки.
4. Прямой коридор относительно оси поезда, ограниченная пригодная дальность.
5. Точки над поверхностью, кластеры и проверка исходными точками.
6. Расстояние от sensor origin до ближайшей принятой точки внутри коридора.
7. UNKNOWN на непригодных данных; NO_OBSTACLE_DETECTED только в пригодной области.

Для каждого параметра записать единицы, значение, диапазон и эксперимент выбора.
Пороги не должны зависеть от имени bag. Не обещать 100/200/300 м без измерений.
